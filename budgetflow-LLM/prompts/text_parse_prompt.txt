<relative_date_handling>
Resolve relative date expressions using the requestDate value provided.
- "오늘" → requestDate
- "어제" → requestDate - 1 day
- "그제" / "그저께" → requestDate - 2 days
- "이번 주 월요일" → most recent Monday on or before requestDate
- Specific dates like "5/12", "5월 12일" → same year as requestDate
- Any other relative expression → null (do not guess)

The following MUST resolve to null. Do NOT guess a specific date:
- "저번 주 화요일" → null
- "지난주에" → null
- "저번달" / "지난달에" → null
- "최근에" → null
- "며칠 전" → null
- input with no date expression → null
</relative_date_handling>
